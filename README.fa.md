## 🚀 نصب سریع

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/SiNaKeEn/NexusNet-PasarGuard/Manager/install.sh)
```

یا نصب دستی از این زیپ:

```bash
chmod +x pg-m
cp pg-m /usr/local/bin/pg-m
pg-m --version   # باید 2.2.2 نشان دهد
```

سپس:

```bash
pg-m
```

دستورات میان‌بر:

```bash
pg-m status                 # وضعیت کانتینرها، URL، منابع
pg-m doctor                 # چک کامل سلامت
pg-m db                     # نمای کلی دیتابیس
pg-m backup [full|lite]     # ساخت بکاپ
pg-m restore FILE           # ریستور / پکیج انتقال
pg-m update                 # آپدیت خود pg-m
pg-m --node-certs           # جاب هفتگی سرت دامنه نود
```

## 🆕 تازه‌های نسخه ۲.۲.۲

### منوی ۱۷ — سرتیفیکیت دامنه‌های نود (بهبود یافته)

| گزینه | کار |
|--------|------|
| **۱. صدور روی همین سرور = مستر** | فقط محلی. **هرگز** IP / پورت / پسورد روت نمی‌پرسد. ذخیره در `/var/lib/pasarguard/certs/<دامنه>/`. |
| **۲. صدور اینجا + ارسال به مستر** | روی **نود** اجرا کن. یک‌بار IP مستر می‌پرسد (فقط نصب کلید SSH؛ پسورد ذخیره نمی‌شود). |
| **۳. لیست همه سرت‌های این سرور** | اسکن دیسک (`/var/lib/pasarguard/certs/`). روی مستر هم سرت‌هایی که از نود Push شده‌اند را نشان می‌دهد. |
| **۴. نمایش مسیرها و تاریخ انقضا** | برای دامنه‌های ثبت‌شده در جاب هفتگی. |
| **۵. حذف یک سرتیفیکیت** | پوشه سرت پنل را پاک می‌کند؛ اختیاری کپی Let's Encrypt را هم. لیست جاب را به‌روز می‌کند. |
| **۶–۹** | اجرای جاب / فعال‌سازی / غیرفعال / ریستارت پنل بعد از تغییر سرت. |

**روش‌های اثبات مالکیت دامنه:** Cloudflare DNS · **ArvanCloud DNS** · Standalone (پورت ۸۰).

کرون هفتگی: هر دوشنبه ساعت ۰۴:۰۰ (`pg-m --node-certs`). فقط وقتی فایل سرت عوض شده کپی می‌کند.

مسیرهایی که در پنل (تنظیمات TLS هاست/نود) می‌گذاری:

```
/var/lib/pasarguard/certs/<دامنه>/fullchain.pem
/var/lib/pasarguard/certs/<دامنه>/key.pem
```

### اصلاحات قبلی (۲.۲.۱)

- گزینه ۱ دیگر اعتبارنامه مستر نمی‌پرسد.
- با انتخاب حالت محلی، تنظیمات قبلی Push پاک می‌شود.
- پشتیبانی DNS اروان کلود اضافه شد.

## 🔐 SSL پنل (منوی ۴) و دامنه‌های نود (منوی ۱۷)

- صدور Let's Encrypt برای یک یا چند ساب‌دامین.
- سرت‌ها به مسیری کپی می‌شوند که کانتینر پنل بخواند.
- هوک تمدید خودکار + امکان ریستارت پنل.
- برای **دامنه نود**: اگر دامنه به همین سرور اشاره می‌کند (یا Cloudflare/Arvan داری) → **گزینه ۱**. اگر دامنه به نود است و فایل باید روی مستر باشد → **گزینه ۲** روی نود.

**نکته بدون API Token:** پروکسی Cloudflare را خاموش کن (DNS only) → با Standalone سرت بگیر → دوباره پروکسی را روشن کن.

## 💾 بکاپ، دیتابیس، انتقال

- آرشیو کامل / لایت با چک‌سام؛ بکاپ خودکار تلگرام؛ ریستور هوشمند.
- نمای کلی دیتابیس برای TimescaleDB / PostgreSQL / MySQL / MariaDB / SQLite.
- انتقال یک‌کلیکی به VPS جدید (پکیج + ریستور + تغییر اختیاری DNS با Cloudflare).

> بکاپ‌ها شامل کلید خصوصی هستند — خصوصی نگه دارید (`chmod 600`).
